개인정보 처리방침

시행일: 2026년 8월 24일 · Travel Ink 1.0

Travel Ink는 개인정보를 개발자 서버에 수집하거나 전송하지 않습니다. 여행 기록은 이 기기에 저장되고, 위치 권한 없이 사용자가 직접 기록합니다.

1. 수집하는 개인정보

회원가입과 로그인이 없으며 이름, 이메일, 전화번호, 기기 식별자를 앱에서 묻거나 저장하지 않습니다. 위치와 이동 경로를 수집하지 않습니다. 분석, 광고, 크래시 리포트 도구를 사용하지 않습니다.

2. 기기에 저장되는 정보

방문한 지역과 랜드마크, 날짜, 메모, 별점, 첨부 사진과 미리보기 이미지, 달성한 업적, 테마 등의 앱 설정이 앱 전용 저장소에 저장됩니다.

3. 외부 전송

앱이 자동으로 외부에 전송하는 정보는 없습니다. 사용자가 지도 이미지 공유 또는 백업 내보내기를 직접 실행한 경우에만 만들어진 파일이 사용자가 선택한 앱이나 저장 위치로 전달됩니다.

4. 기기 백업

사용자가 iCloud 백업을 켜 둔 경우 운영체제가 앱 데이터를 사용자 본인의 iCloud 백업에 포함할 수 있습니다. 이는 Apple이 제공하는 기기 백업 기능이며, 원하지 않으면 기기 설정에서 Travel Ink를 백업 대상에서 제외할 수 있습니다.

5. 권한

위치 권한과 백그라운드 위치 추적을 사용하지 않습니다. 사진 보관함과 카메라는 방문 기록에 사진을 첨부할 때만 요청합니다. 첨부 사진은 저장 과정에서 다시 인코딩되어 촬영 위치와 기기 정보 같은 EXIF 메타데이터가 제거됩니다.

6. 데이터 삭제

기록을 삭제하면 연결된 사진 파일도 함께 삭제됩니다. 앱을 삭제하면 기기에 저장된 기록, 사진, 설정이 삭제됩니다. 별도의 서버 사본이 없으므로 사용자가 만든 백업 파일이나 iCloud 기기 백업이 있을 때만 복원할 수 있습니다.
